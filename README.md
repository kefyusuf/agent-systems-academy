# Agent Systems Academy

A local-first, Astro-based learning platform for reliable coding-agent engineering.

## Project status

The repository is initialized. The verified v0.7 source package has not yet been imported into this repository; do not treat this README as a published academy release.

Planned source: 14 modules, 42 lessons, 55 glossary entries, four deterministic teaching labs, task lifecycle, context/cache, compaction/handoff, reliability and evaluation robustness workshops.

## Engineering constraints

- Curriculum and teaching simulations only; no live LLM, agent execution, credential handling or MCP server.
- Documentation and identifiers in English; learner-facing content in Turkish.
- Tests and evidence before promotion to the default branch.
- A GitHub Pages deployment is valid only after the complete source, tests and portable build are present and checked.

See project releases and follow-up pull requests once the v0.7 import is complete.
