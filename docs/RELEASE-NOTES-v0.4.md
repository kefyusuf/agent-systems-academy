# Release notes — v0.4.0

## Scope

One focused, offline Context & Cache Studio attached to the existing Task Lifecycle workshop. **No new broad platform capability** was authorized or implemented.

## Added

- Nine deterministic context/cache failure-injection cases with A/B risky/guarded comparisons.
- Visual diff of two cache checkpoint prefixes, model-derived hit/miss classifications, illustrative two-request cost comparison.
- Revision freshness, evidence receipt, source trust, action scope, handoff integrity and context budget checks.
- Downloadable English architecture workbook with nine fixture exercises, eval matrix, trace checklist, sample envelope and ADR prompt.
- Dedicated Node unit tests and UI routing/interaction tests.
- Source links to official OpenAI, Anthropic and MCP documentation.

## Preserved

- 14 modules, 42 lessons, 55 glossary terms, four labs.
- Nine-case v0.3 lifecycle workshop and its logic.
- Browser-only implementation, Turkish learning interface, English repository documentation, static offline preview.
- Original progress storage key, preserving local lesson completions.

## Limits

All values are local deterministic teaching assumptions, not real provider observations, LLM calls, MCP interactions, security enforcement or real test verification. `ELIGIBLE_FOR_DONE` describes simulation invariants only. Actual Astro build status must be reported from a real execution log.
